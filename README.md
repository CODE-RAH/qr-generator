این پروژه یک ابزار ساده و سریع برای **تولید کد QR** با استفاده از پایتون است. کاربر می‌تواند هر متن، لینک یا اطلاعاتی را وارد کند و در کمتر از یک ثانیه یک **کد QR استاندارد** دریافت نماید.

# ⌨️ نحوه استفاده

پس از اجرا، متن یا لینک موردنظر خود را وارد کنید:

text

---

# 💡 مثال کد

python
import qrcode

data = input("Enter your text or URL: ")

qr = qrcode.QRCode(
version=1,
box_size=10,
border=4
)

qr.add_data(data)
qr.make(fit=True)

img = qr.make_image(fill_color="black", back_color="white")
img.save("qrcode.png")

print("QR Code saved as qrcode.png")
